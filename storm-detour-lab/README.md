# 태풍을 지나는 여행 — 최단 항로 수학 비행 (v0.4)

인천에서 고른 공항까지 여객기를 타고 날아가며, 가상의 원형 태풍을 피하는 **최단 항로(접선 + 원호 + 접선)** 가
기내 노트에 한 단계씩 계산되는 감상형 수학 여행 시뮬레이터입니다.

수학 기준 문서: 「원형 태풍 회피 최단 항로의 계산 — 도착점 A = (t, 0) 기준 전체 유도」
(공통수학2 · 중학교 삼각비 · 평면 모델)

## 여행 흐름

0. **인트로** — 캐리어를 끄는 여행자가 인천공항 출국장에 들어와 체크인 카운터로 갑니다.
1. **항공 예약 (가상 항공사 SIMPUL AIR)** — ① 항공편 검색(국가 → 공항, OurAirports 86,000여 곳, 날짜·탑승객)
   → ② 항공편 선택(가상 편명·시각·운임) → ③ **기상 안내**: 안내원이 태풍 경보를 알리고, 지도에서 태풍 위치·반지름 배치.
   관통 조건 `r² − b² > 0`, `0 < a − h < a + h < t` 를 만족해야 다음 단계로 갑니다 → ④ 좌석 선택 → ⑤ 탑승권(L_min 안내).
2. **비행 (약 4분, ×1·×2·×4)** — 쌍발 여객기(가상 기종 SA-321, 오리지널 모델)를 날개 뒤 어깨 높이에서 보는 숄더 샷.
   인천 활주로에서 이륙 활주 → 상승 → 순항 → 하강 → 목적지 활주로 착륙. 공항에는 활주로·유도로·계류장·
   유리 터미널·탑승교·관제탑·격납고가 있습니다(실제 공항 배치가 아닌 양식화된 모형, 활주로는 항로 방향에 맞춤).
   태풍은 눈벽·중심 구름덮개·나선 띠·바깥 구름벽·비 커튼·번개로 보이고, 접점 P에서 기체가 기울며 원호로 선회합니다.
3. **기내 노트** — 비행 시각에 맞춰 문서의 계산이 이번 여행의 숫자로 적히며, 모든 식은 KaTeX로 조판됩니다.
   계기판의 **레이더 = 계산 좌표평면**(x축 = 기수 방향)에 B₁, B₂, P, Q, R이 차례로 나타납니다.
4. **도착 엽서** — 직선 t와 L_min 비교, 계산 요약, 코사인표 보간 오차.

## 실행·배포

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 수학·여행·데이터 테스트
npm run build        # dist/ (GitHub Actions가 main 푸시 때 자동 배포)
npm run prepare-airports   # 공항 데이터 다시 만들기 (필요할 때만)
```

## 테스트가 확인하는 것

- 문서 9~10장 예제(t=10, C=(4,1), r=2): B₁, B₂, s, ℓ_O=√13, ℓ_A=√33, P, Q, H, R, CR, z, 보간 직선,
  α̂≈12.348164°, 호≈0.862064, L_min≈10.212178, 정확값과의 차이≈0.000631
- 경계 상황(만나지 않음·접함·선분 밖·끝점이 원 안·b=0·b<0)
- 무작위 태풍 3,000개: P, Q가 원 위·반지름⟂접선·같은 쪽, R이 두 접선 위, 2α<180°,
  0 ≤ α − α̂ < 0.25°, |ΔL| < πr/360, 반대쪽 원호가 더 길고 접선 합은 같음
- 1° 표 보간 최대 오차 ≈ 0.249995°
- 세계 10개 공항 × 태풍 좌우: 탑승 가능, 끝점 = 목적지, 날짜변경선 연속, 시간 배분이 P·Q에 정확히 맞음

## 알아 둘 점

- **근삿값이 직선보다 짧아지는 경우**: 태풍이 항로를 아주 살짝 걸치면 보간 오차(최대 πr/360)가
  실제 추가 거리보다 커서 L_min(근삿값) < t 가 될 수 있습니다. 앱은 이때 노트에 이유를 설명합니다.
- 계산은 인천 중심 평면(km)에서 하고, 지도·3D 지구에는 같은 원과 경로를 되돌려 그립니다.
  지구 곡률 보정은 다루지 않습니다(문서 범위와 같음). 태풍은 실제 기상이 아닌 원형 진입 금지 구역입니다.
- 3D 화면은 WebGL이 필요합니다. 학교 기기에서 느리면 '풍경만 보기'를 끄고 ×2 속도로 보거나 창 크기를 줄이세요.
